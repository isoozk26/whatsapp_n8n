# Proje Analiz Raporu: WhatsApp AI - v13 PostgreSQL Outbox

## Mimari Özet

**Sistem:** FiltreOto WhatsApp AI — Evolution API → n8n workflow → PostgreSQL outbox → OpenAI → Evolution API geri gönderim.

**Akış (3 şerit):**
1. **Webhook Ingestion:** Webhook1 → Normalize → Auth → Valid Event? → Ingest Message → Respond
2. **AI Processing (15sn schedule):** Circuit Gate → Claim Batches → Store Context → AI Agent → Parse → Vehicle Catalog? → Complete
3. **Delivery (schedule):** Circuit Gate → Claim Deliveries → Prepare → Send → Record Result

**Bileşenler:** 33 node, 9 Code (JS), 6 IF, 9 PostgreSQL, 1 HTTP Request, 3 Respond, 2 AI/LangChain, 2 Trigger. 3 credential: PostgreSQL, OpenAI, Evolution API.

**9 PostgreSQL fonksiyonu:** `ingest_message`, `circuit_allows`, `claim_ready_batches`, `resolve_vehicle_context`, `complete_ai_batch`, `record_service_result`, `record_ai_failure`, `claim_deliveries`, `record_delivery_result`.

## Değişiklik: Her Mesaj Yöneticiye Bildirim Gitsin + ++ Komutu Bildirimi

### Talep
1. `notifyAdmins` her müşteri mesajında `true` olacak (hiç `false` olmayacak)
2. `++` komutu gönderildiğinde yöneticilere "SİSTEM MANUEL" bildirimi gidecek

### Değişiklik 1: build_workflow.py — Parse AI Output
**Dosya:** `build_workflow.py` (satır 173)
- `let notifyAdmins = false;` → `let notifyAdmins = true;`
- Tüm `notifyAdmins = false` satırlarını kaldır (satır 246, ve Apply Catalog Decision'daki satır 405, 408, 414)

### Değişiklik 2: build_workflow.py — Apply Catalog Decision
**Dosya:** `build_workflow.py` (satır 397-417)
- `let notifyAdmins = Boolean(policy.notifyAdmins);` → `let notifyAdmins = true;`
- Tüm `notifyAdmins = false` satırlarını kaldır (satır 405, 408, 414)

### Değişiklik 3: ++/-- Komut Bildirimi
**Dosya:** `build_workflow.py` — Normalize Payload JS
- `++` komutu: `command: "pause"` → bildirim: "SİSTEM MANUEL"
- `--` komutu: `command: "resume"` → bildirim: "SİSTEM OTOMATİK"
- Bu bildirim `ingest_message` PostgreSQL fonksiyonuna `p_command` parametresi ile gidiyor
- `ingest_message` fonksiyonu command geldiğinde outbox'a admin bildirimi yazmalı
- **Çözüm:** `db/migrations/` dosyasına yeni migration ekle: `ingest_message` fonksiyonunda `p_command`='pause' ise admin_phone_a ve admin_phone_b'ye "SİSTEM MANUEL" mesajı, 'resume' ise "SİSTEM OTOMATİK" mesajı outbox'a yaz

### Değişiklik 4: wf_deploy.py ile canlıya al
- `build_workflow.py` → `python build_workflow.py` (workflow.json yeniden üretilir)
- Migration uygula: `python tools/wf_migrate_via_n8n.py`
- `python tools/wf_deploy.py workflow.json` ile deploy

## Deploy Planı — n8n Self-Hosted

### Ön Koşullar
- n8n >= 1.31 (LangChain nodes için)
- `n8n-nodes-langchain` paketi kurulu (1.31+ varsayılan olarak gelir)
- n8n UI'da credential'lar oluşturulmuş: `OpenAi account`, `WhatsApp State PostgreSQL`, `Evolution API`
- Environment variable'lar set edilmiş: `WEBHOOK_SECRET`, `EVOLUTION_API_KEY`, `EVOLUTION_API_URL`, `N8N_OPENAI_CREDENTIAL_ID`

### Adım 1: workflow.json Yeniden Oluştur
`build_workflow.py` değiştirildi (EVOLUTION_API_URL artık env var'dan okunuyor, OpenAI fallback kaldırıldı). Deploy öncesi rebuild şart.

```bash
$env:EVOLUTION_API_URL = "https://evo.filtreoto.online"
$env:N8N_OPENAI_CREDENTIAL_ID = "<n8n OpenAI credential ID>"
python build_workflow.py
python tools/wf_validate.py
```

### Adım 2: Diff Kontrolü
workflow.json'daki değişiklikleri incele — sadece Send Delivery URL'si ve credential ref'leri değişmeli.

### Self-Hosted Dikkat Edilecekler
1. **Reverse proxy**: `X-Webhook-Secret` header'ının forward edildiğinden emin ol (nginx/cloudflare bazı header'ları strip eder)
2. **LangChain**: n8n < 1.31 ise `@n8n/n8n-nodes-langchain` manuel kurulmalı
3. **$env.* değişkenleri**: n8n container'ına veya `.env` dosyasına set edilmeli
4. **Webhook URL**: `https://<n8n-domain>/webhook/evolution-webhook` olarak Evolution API'ye ayarlanmalı
5. **SSL**: n8n self-hosted'da reverse proxy SSL sonlandırması yapmalı
6. **saveDataSuccessExecution: "all"**: Teşhis için gerekli, self-hosted'da varsayılan olarak gelir
7. **executionTimeout: 600**: Self-hosted'da desteklenir, cloud'da limit olabilir
