# GPT-5.6 Sol Modelini MiMoCode'a Ekleme

## Amaç
Mevcut MiMoCode kurulumuna OpenAI GPT-5.6 Sol modelini eklemek.

## Yapılacak Değişiklik

**Dosya:** `~/.config/mimocode/mimocode.jsonc`

### 1. OpenAI Provider'ı Ekle
`provider` objesine `openai` provider'ı eklenir:
```jsonc
"openai": {
  "options": {
    "baseURL": "https://api.openai.com/v1",
    "apiKey": "sk-KULLANICI-ANAHTARI"
  },
  "name": "openai"
}
```

### 2. Model Grubu Ekle (opsiyonel ama kullanışlı)
`model_groups` objesine `gpt56` grubu eklenir:
```jsonc
"gpt56": {
  "default": "openai/gpt-5.6-sol",
  "models": [
    "openai/gpt-5.6-sol",
    "openai/gpt-5.5",
    "openai/gpt-5.4"
  ]
}
```

### 3. Varsayılan Modeli Değiştir
`"model"` alanını `"openai/gpt-5.6-sol"` olarak güncelle.

## Doğrulama
- `mimo models` komutuyla OpenAI modellerinin listelendiğini kontrol et
- Yeni session'da modelin doğru seçildiğini doğrula

## Notlar
- API anahtarını kullanıcıdan alıp config'e yazacağız
- Config değişikliği sonrası restart gerekmez (bir sonraki turn'da okunur)
- OpenAI model ID'leri kesin olmayabilir, `mimo models` ile doğrulanmalı
