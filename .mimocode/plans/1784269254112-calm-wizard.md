## Değişiklik 2: Manuel Mod TTL (30 dakika)
**Sorun**: Handoff sonrası `_manualModes[senderNumber] = true` olarak ayarlanıyor ama süresi yok. Müşteri süresiz sessiz kalabilir.

**Çözüm**: `_manualModes` değerini boolean yerine nesne olarak sakla: `{ enabled: true, createdAt: timestamp }`

### 2a. Batch Collector (`batch_collector_js`, satır ~109)
**Mevcut**:
```javascript
if (fromMe || staticData._manualModes[senderNumber] === true) {
  return [{ json: { _action: 'ignore' } }];
}
```

**Yeni**:
```javascript
const manualMode = staticData._manualModes[senderNumber];
if (fromMe || (manualMode && manualMode.enabled === true)) {
  // TTL kontrolü: 30 dakika sonra otomatik kaldır
  if (manualMode && manualMode.enabled === true && manualMode.createdAt) {
    const MANUAL_TTL_MS = 30 * 60 * 1000;
    if (Date.now() - Number(manualMode.createdAt) > MANUAL_TTL_MS) {
      delete staticData._manualModes[senderNumber];
      // Mesajı yutma, devam et
    } else {
      return [{ json: { _action: 'ignore' } }];
    }
  } else {
    return [{ json: { _action: 'ignore' } }];
  }
}
```

### 2b. ++ Komutu (Batch Collector, satır ~83)
**Mevcut**:
```javascript
if (isAuthorized && messageText === '++') {
  staticData._manualModes[senderNumber] = true;
```

**Yeni**:
```javascript
if (isAuthorized && messageText === '++') {
  staticData._manualModes[senderNumber] = { enabled: true, createdAt: Date.now() };
```

### 2c. -- Komutu (Batch Collector, satır ~96)
Zaten `delete staticData._manualModes[senderNumber]` kullanıyor, değişiklik gerekmez.

### 2d. Parse AI Output - Handoff (`parse_ai_output_js`, satır ~895)
**Mevcut**:
```javascript
if (action === 'handoff' || pauseAutomation === true) {
  staticData._manualModes[senderNumber] = true;
}
```

**Yeni**:
```javascript
if (action === 'handoff' || pauseAutomation === true) {
  staticData._manualModes[senderNumber] = { enabled: true, createdAt: Date.now() };
}
```

### 2e. Stale Batch Check (`stale_batch_check_js`, satır ~179)
**Mevcut**:
```javascript
if (staticData._manualModes[number] === true) {
  delete staticData._batches[number];
  continue;
}
```

**Yeni** (TTL kontrolü ekle):
```javascript
const manualEntry = staticData._manualModes[number];
if (manualEntry && manualEntry.enabled === true) {
  const MANUAL_TTL_MS = 30 * 60 * 1000;
  if (manualEntry.createdAt && (Date.now() - Number(manualEntry.createdAt)) > MANUAL_TTL_MS) {
    delete staticData._manualModes[number];
  } else {
    delete staticData._batches[number];
    continue;
  }
}
```

### 2f. Finalize Batch - Handoff (`clear_batch_js`, satır ~982-983)
**Mevcut**:
```javascript
if (input.pauseAutomation === true || input.action === 'handoff') {
  staticData._manualModes[senderNumber] = true;
}
```

**Yeni**:
```javascript
if (input.pauseAutomation === true || input.action === 'handoff') {
  staticData._manualModes[senderNumber] = { enabled: true, createdAt: Date.now() };
}
```
