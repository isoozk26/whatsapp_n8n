# Webhook Güvenlik Mimarisi — URL Token + IP Whitelist

## Amaç

Evolution API v2.3.7 ile n8n arasındaki webhook bağlantısını iki katmanla güvence altına almak:
1. **URL Token:** Query parameter ile basit token doğrulama
2. **IP Whitelist:** Cloudflare/Nginx ile yalnızca Evolution API sunucusundan gelen isteklere izin verme

---

## Katman 1: URL Token Doğrulama

### Durum
Mevcut `Webhook Auth` node'u `X-Webhook-Secret` header'ı kontrol ediyor. Evolution API v2.3.7 panelinde custom header eklemek için alan olmadığı için bu koruma **etkin değil**.

### Çözüm
Webhook URL'sine query parameter olarak token eklenir, n8n tarafında `$json.query` ile okunur.

### Değişiklikler

#### 1. `build_workflow.py` — `webhook_auth_js` Değişikliği

**Mevcut kod (satır 40-54):**
```javascript
const WEBHOOK_SECRET = process.env.WEBHOOK_SECRET || staticData._webhookSecret || '';
if (WEBHOOK_SECRET) {
  const receivedSecret = $json.headers?.['x-webhook-secret'] || $json.headers?.['X-Webhook-Secret'] || '';
  if (receivedSecret !== WEBHOOK_SECRET) {
    return [{ json: { _action: 'auth_failed', reason: 'invalid_webhook_secret' } }];
  }
}
```

**Yeni kod:**
```javascript
// URL Token Dogrulama: Evolution API v2.3.7 custom header desteklemediginden
// webhook URL'sine ?token= parametresi eklenir, burada dogrulanir
const AUTH_TOKEN = process.env.WEBHOOK_AUTH_TOKEN || staticData._webhookAuthToken || '';
if (AUTH_TOKEN) {
  const receivedToken = $json.query?.token || '';
  if (receivedToken !== AUTH_TOKEN) {
    console.error('[Webhook Auth] Basarisiz: Gecersiz veya eksik URL token');
    return [{ json: { _action: 'auth_failed', reason: 'invalid_url_token' } }];
  }
}
```

**Not:** `staticData._webhookAuthToken` n8n panelinden de ayarlanabilir. Bu sayede token değiştirildiğinde workflow'u yeniden deploy etmeye gerek kalmaz.

#### 2. Evolution API Webhook URL Değişikliği

Evolution API panelinde webhook URL'si şöyle değiştirilmeli:
```
Eski: https://n8n.filtreoto.online/webhook/evolution-webhook
Yeni: https://n8n.filtreoto.online/webhook/evolution-webhook?token=RANDOM_SECRET
```

**Token üretimi (bir kez):**
```python
import secrets
print(secrets.token_urlsafe(32))
```

#### 3. n8n Ortam Değişkeni

n8n panelinde veya Coolify'da:
```
WEBHOOK_AUTH_TOKEN=uretilen_token_degeri
```

#### 4. `tools/wf_security.py` — Token Kontrolü

Yeni bir pattern eklenmeli:
```python
(r'(?i)WEBHOOK_AUTH_TOKEN["\x27]?\s*[:=]\s*["\x27][A-Za-z0-9._-]{20,}["\x27]', 'Webhook Auth Token (hardcoded)'),
```

#### 5. `tools/test_workflow_contract.py` — Contract Test

Yeni bir assertion:
```python
# URL token auth contract
auth = next(n for n in workflow["nodes"] if n["name"] == "Webhook Auth")
auth_code = auth["parameters"]["jsCode"]
assert "$json.query?.token" in auth_code, "URL token auth missing"
assert "auth_failed" in auth_code, "Auth failure response missing"
```

## Katman 2: IP Whitelist (Cloudflare/Nginx)

### Durum
Şu anda herhangi bir IP kısıtlaması yok. Herhangi bir kaynaktan webhook isteği gönderilebilir.

### Çözüm
Evolution API sunucusunun IP adresi tespit edilip, webhook endpoint'ine yalnızca o IP'den erişim izni verilir.

### Uygulama Adımları

#### 1. Evolution API IP'sini Öğrenme

Coolify'da Evolution servisinin logs'undan veya sunucudan:
```bash
# Evolution API sunucusunda
curl -s ifconfig.me
# veya
curl -s ipinfo.io/ip
```

#### 2. Cloudflare Firewall Kuralı

Cloudflare Dashboard → Security → WAF → Custom Rules:

**Kural Adı:** `webhook-ip-restrict`
**Koşul:**
```
(http.request.uri.path eq "/webhook/evolution-webhook" and ip.src ne EVOLUTION_IP)
```
**Eylem:** Block

**Not:** Cloudflare'da URI path-based kural oluştururken, query string dahil edilmeli. Alternatif olarak `ip.src ne` ile yalnızca Evolution IP'sine izin verilebilir.

#### 3. Nginx Alternatifi (Eğer Cloudflare kullanılmıyorsa)

```nginx
location /webhook/evolution-webhook {
    allow EVOLUTION_IP;
    deny all;

    proxy_pass http://n8n_backend;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

#### 4. IP Değişikliği Senaryosu

Evolution API sunucusunun IP'si değişirse:
1. Yeni IP'yi öğren
2. Cloudflare kuralını güncelle
3. Nginx config'i güncelle ve reload

**Otomasyon önerisi:** IP değişikliğini otomatik algılayan bir monitoring scripti oluşturulabilir.

## Riskler ve Notlar

- **Token sıfırlama:** `staticData._webhookAuthToken` ile n8n panelinden token değiştirilebilir, deploy gerekmez
- **Geriye uyumluluk:** Eski `X-Webhook-Secret` header kontrolü kaldırılıyor, Evolution API v2.3.7 zaten desteklemiyor
- **IP değişikliği:** Evolution API sunucusunun IP'si değişirse tüm whitelist'ler güncellenmeli
- **Cloudflare planı:** Firewall custom rules için Pro planı gerekebilir
